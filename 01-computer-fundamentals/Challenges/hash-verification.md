# Challenge: Hash Verification

## File
RobloxPlayerInstaller.exe

## Command
sha256sum "RobloxPlayerInstaller.exe"

## SHA-256
[7ad01a4f2180e5efffb8f873e891a498fea9b85950f886e2d25fc486ab ]

## What I learned
SHA-256 produces a fingerprint based on the contents of a file.
Comparing it with a trusted expected hash can verify that the file has not changed or become corrupted.

## Important
A matching hash verifies integrity; it does not by itself prove that a file is safe.

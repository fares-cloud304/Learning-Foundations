Challenge 1 — Service Model Quiz
Objective

Classify common cloud services according to the three main cloud service models:

IaaS — Infrastructure as a Service
PaaS — Platform as a Service
SaaS — Software as a Service
Answers
Cloud Service	Model	Reason
Gmail	SaaS	You use a complete email application without managing the underlying servers or infrastructure.
AWS EC2	IaaS	Provides virtual machines/compute infrastructure that you control and configure.
Google App Engine	PaaS	Provides a managed platform for deploying applications without managing the underlying infrastructure directly.
Microsoft 365	SaaS	Provides complete applications such as Word, Excel, and Outlook as cloud services.
Azure Virtual Machines	IaaS	Provides virtual machines where you manage the operating system and software running on the VM.
Final Classification
IaaS
├── AWS EC2
└── Azure Virtual Machines

PaaS
└── Google App Engine

SaaS
├── Gmail
└── Microsoft 365
Key Concept

The easiest way to distinguish them is how much the cloud provider manages for you:

        MORE MANAGEMENT BY YOU
                ↓
IaaS → PaaS → SaaS
                ↓
        MORE MANAGEMENT BY PROVIDER
IaaS: You get infrastructure and manage much of the software stack.
PaaS: You focus mainly on your application; the provider manages the platform/infrastructure.
SaaS: You simply use the finished application.

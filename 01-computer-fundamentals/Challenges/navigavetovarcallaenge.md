# Lesson 6 — Challenge 1: Navigate to /var/log


## Task


Starting from my home directory:


1. Navigate to `/var/log`
2. List the files
3. Return to my home directory
4. Complete it in 5 commands or fewer.


## Commands Used


```bash
cd /var/log
ls
cd ~
What I Did

I started in my home directory and used cd /var/log to navigate to the /var/log directory.

I used ls to list the files and directories inside /var/log.

I then used cd ~ to return to my home directory.

I also used pwd to verify my current location.

What I Learned
cd changes the current directory.
cd /var/log moves directly to /var/log.
ls lists the contents of a directory.
pwd shows the current working directory.
cd ~ returns to my home directory.
/var/log contains system and application log files.

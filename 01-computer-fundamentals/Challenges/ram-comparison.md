# Challenge: RAM Comparison with AWS Instances

## Objective

Compare my computer's RAM with three AWS EC2 instance types and identify the closest match.

## My Computer

- RAM: 32 GB

## AWS Instance Comparison

I compared my RAM with three AWS instance types.

The closest match was:

**r5.xlarge**

It provides **32 GiB of memory**, which is closest to my computer's 32 GB of RAM.

## Instance Family Naming

I learned that AWS instance families give clues about what they are designed for:

- `r` = memory optimized
- `m` = general purpose
- `c` = compute optimized
- `t` = burstable general purpose

## What I Learned

AWS instances can be selected based on the resources a workload needs, including CPU and memory.

The `r5.xlarge` instance is designed for workloads that benefit from having more memory.

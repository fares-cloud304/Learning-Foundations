# CPU, RAM, Storage & Cloud

## CPU
The CPU executes instructions.

Cores are like workers. More cores allow more work to happen in parallel.

Clock speed is measured in GHz.

## RAM
RAM is temporary working memory.

It is like a desk where currently active programs work.

## Storage
Storage such as SSDs keeps data permanently.

Unlike RAM, storage retains data when the computer is powered off.

## AWS Storage

### EBS
EBS is block storage attached to an EC2 instance.
It is similar to a virtual hard drive.

### S3
S3 is object storage used for things such as files, backups and datasets.

### EFS
EFS provides shared file storage.

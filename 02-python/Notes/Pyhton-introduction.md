Two Ways to Run Python
Python code can be executed in two different ways depending on what you are trying to do:

Interactively (The REPL):
You type one line of code at a time, and Python executes it immediately.
Great for quick tests, math, and experimenting.
Accessed by typing python in the terminal (shows the >>> prompt).
As a Script (.py file):
You write multiple lines of code, save it in a file ending in .py (e.g., hello.py), and run the whole file at once.
Great for actual programs, automation, and cloud engineering scripts.
Executed by typing python hello.py in the terminal.
Why Python Dominates Cybersecurity & Cloud Engineering
Python isn't just a popular language; it is the most-used language in cybersecurity and cloud engineering. Here is why:

Highly Readable: Python reads almost like plain English. This means fewer mistakes when writing complex security or infrastructure scripts.
Cloud SDKs: Every major cloud provider has official Python libraries:
AWS: boto3
Azure: azure-sdk-for-python
GCP: google-cloud-python
Built for Automation: Instead of manually clicking through the AWS web console to set up 50 firewalls, a cloud engineer writes a Python script to do it in 5 seconds.
Key Takeaway
As a future Cloud Engineer, Python is my primary tool. I will use the REPL to test small commands, but I will use .py scripts to automate real cloud infrastructure.

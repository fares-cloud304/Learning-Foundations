Phase: 2 - Python Programming
Lesson: 1 - Python Introduction & Installation

Objective
Research the origins of Python, its creator, and the real reason behind its name.

Findings
Creator: Guido van Rossum
Year of Release: 1991
The Name Origin: Python is NOT named after the snake. Guido van Rossum named it after his favorite BBC comedy series, Monty Python's Flying Circus.
Cloud Engineering Context
Why does this random history matter? Because it explains Python's culture. Python was designed to be highly readable, fun to use, and slightly humorous. This "developer experience" is why Python became the #1 language for cloud automation (like AWS Boto3) and security scripting—engineers can write complex cloud infrastructure code that actually reads like plain English, reducing mistakes.
